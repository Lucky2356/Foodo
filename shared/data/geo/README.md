# Города и торговые сети

## cities.json

Производный набор из справочника городов России **hflabs/city** (https://github.com/hflabs/city),
лицензия **Creative Commons Attribution-ShareAlike 4.0** (CC BY-SA 4.0). Авторство: HFLabs.
Файл `cities.json` распространяется на тех же условиях (CC BY-SA 4.0); лицензия кода Foodo
на этот файл не распространяется.

Исходный CSV сохранён рядом (`hflabs-city.csv`). Пересборка: `python3 scripts/build_cities.py`.
Часовой пояс сопоставлен по смещению UTC из исходных данных с типичной зоной IANA (в России нет
перехода на летнее время), поэтому зона может отличаться названием при совпадающем смещении.

## chains.json

Список крупных продуктовых сетей России и регионов их присутствия. Сведения о присутствии
составлены по общедоступной информации и **не проверены** (`presence_verified: false`):
уточняйте их в административной панели. Наличие сети в списке не означает, что Foodo получает её
цены или ассортимент: цены приходят из источников, перечисленных в `docs/PRICES.md`.
