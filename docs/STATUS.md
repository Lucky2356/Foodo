## Ограничения и блокеры

- **Пищевая ценность**: 79 из 445 продуктов — оценки разработчика (`verified: false`, помечены на странице рецепта): продукты без точного аналога в USDA и шведской базе (кефир 1 %, творог, ряженка, брынза, сулугуни, колбасы, слабосолёная форель, шпроты, аджика и другие соусы, смеси специй, сухой чай и кофе и др.). Российского справочника с открытой лицензией не нашлось (база ФИЦ питания и таблицы Скурихина — без открытой лицензии); финская Fineli закрыта проверкой Cloudflare от автоматических запросов. У шведских продуктов витамин D не переносится (другое определение), витамин A — только у продуктов без каротиноидов. У USDA-продуктов часть витаминов в наборе не измерена (например, E у 45 продуктов) — они показываются как неизвестные. Витамин A хранится в РЭ, как в нормах МР; ненулевые оценки витамина A (в RAE) в РЭ не переводятся и показаны как неизвестные.
- **Присутствие сетей по регионам** — по открытым данным, не сверено.
- **Сервер production** не развёрнут: подготовлена установка без консоли — workflow **Server** (настройка Ubuntu-сервера по SSH, HTTPS, автообновление из релизов, ежедневные резервные копии, восстановление), скрипты проверяются в CI на чистой машине. Нужны от владельца: VPS с Ubuntu 22.04/24.04, домен с A-записью, почтовый ящик для писем и секреты репозитория (`docs/DEPLOYMENT.md`, раздел 2). До этого публично доступен только гостевой режим на GitHub Pages.

## Следующий шаг

Для аккаунтов и семейного доступа: владелец арендует VPS, покупает домен, заводит почтовый ящик и вписывает секреты репозитория, затем запускает *Actions → Server → setup* (`docs/DEPLOYMENT.md`, раздел 2); после этого — проверка HTTPS, health и основного сценария на настоящем адресе. Пищевая ценность 338 продуктов перенесена из USDA FoodData Central SR Legacy (28.10.2026), нормы витаминов для взрослых сверены с МР 2.3.1.0253-21 (28.10.2026); все семь витаминов набора, включая A (в РЭ), учитываются при подборе. Ещё 28 продуктов — из шведской Livsmedelsdatabasen (30.10.2026). Остаются оценки для 79 продуктов без аналога.
