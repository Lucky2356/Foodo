## Ограничения и блокеры

- **Пищевая ценность** продуктов — оценочные значения разработчика (`verified: false`), помечены в интерфейсе. Нужен импорт проверенного справочника.
- **Нормы витаминов МР 2.3.1.0253-21** внесены без доступа к тексту документа — статус «не сверено»; требуется сверка владельцем.
- **Присутствие сетей по регионам** — по открытым данным, не сверено.
- **Сервер production** не развёрнут: нужны сервер, домен и SMTP владельца (инструкция — `docs/DEPLOYMENT.md`). До этого публично доступен только гостевой режим на GitHub Pages.
- **Лицензия** не выбрана (решение владельца).
