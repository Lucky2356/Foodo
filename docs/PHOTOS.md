# Фотографии блюд

Фотографии берутся из Wikimedia Commons и Openverse (Flickr и другие коллекции, которые индексирует Openverse) только под свободными лицензиями: CC0, общественное достояние, CC BY, CC BY-SA. Лицензии NC и ND не используются. Каждая фотография показывается с автором, лицензией и ссылкой на страницу файла. Если подходящей фотографии нет, у рецепта остаётся рисованная обложка. Она не выдаётся за фото блюда.

## Как фотографии попадают в Foodo

Всё выполняется в GitHub Actions, workflow **Photos** (`.github/workflows/photos.yml`), код в `scripts/photos/`.

1. **Кандидаты.** Для каждого рецепта без решения выполняется поиск в Commons по запросам из `scripts/photos/queries.txt` и `queries_*.txt`.
   - За один запуск обрабатывается не больше 200 рецептов без решения (`PHOTO_BATCH`), чтобы задание укладывалось в лимит времени. Следующий запуск продолжает с оставшимися.
   - Если в Commons меньше 6 подходящих кандидатов, остальные места добирает Openverse по первому запросу. Openverse без ключа ограничивает число запросов. Когда лимит исчерпан, прогон продолжается только с Commons, а оставшиеся рецепты получат кандидатов при следующем запуске.
   - Лимит можно поднять: владелец регистрирует приложение в Openverse API и добавляет секреты `OPENVERSE_CLIENT_ID` и `OPENVERSE_CLIENT_SECRET`. Это необязательно.
   - Отбираются: свободная лицензия без ограничений, JPEG/PNG/WebP, не меньше 500×350, без логотипов, карт, плакатов и рисунков.
   - До 6 кандидатов на рецепт выводятся на пронумерованные контактные листы (артефакт `photos`).
2. **Визуальная проверка.** Каждый лист просматривается человеком или ревьюером. Фото подходит, только если на нём действительно это блюдо и в подходящем виде.
   - Решение записывается в `shared/data/photos/selection.json`: `"рецепт": "File:Название.jpg"` (Commons), `"рецепт": "openverse:<id>"` (Openverse) или `null`, если подходящего фото нет.
3. **Применение.** Для выбранных файлов workflow заново проверяет лицензию и скачивает копию шириной 800 px, затем сохраняет её в WebP. Уже добавленные в репозиторий фото не скачиваются повторно. При ответе Wikimedia 403/429 загрузка повторяется с паузой; файл, который так и не скачался, попадает в список проблем, а остальные применяются.
   - Возвращает `credits.json`: автор, лицензия, ссылки на лицензию и страницу файла.
   - Файлы сохраняются в `frontend/public/photos/<рецепт>.webp` (800 px) и `frontend/public/photos/thumb/<рецепт>.webp` (400 px для карточек). Данные об авторе и лицензии — в `shared/data/photos/credits.json`; сборщик каталога (`scripts/catalog/build.py`) переносит их в поле `image` рецепта, в том числе для рецептов из текстовых источников.

Фотографии хранятся на сайте Foodo, а не загружаются с серверов Wikimedia. Поэтому они работают офлайн, и при просмотре рецепта браузер не обращается к сторонним сайтам.

## Текущий набор (21.10.2026)

- Решение принято для всех 1000 рецептов: фото выбрано для **600**, у остальных подходящего свободного фото не нашлось — у них рисованная обложка своей категории.
- Первые 300 рецептов проверены 16.10.2026 (1455 кандидатов), 700 новых — 20–21.10.2026 порциями по 200. Если одно и то же фото подходило к двум блюдам, второе блюдо оставлено без фото. Восемь выбранных фото из Openverse не удалось скачать: Openverse не отвечает на запросы с серверов GitHub. Эти рецепты пока без фото; при повторной проверке можно выбрать другой кандидат из Commons.
- Отклонялись фото другого блюда, с другим основным ингредиентом (например, креветки вместо курицы — это важно для аллергий), упаковки, рисунки, интерьеры и фото, где блюдо не видно.
- Лицензии выбранных файлов: CC BY-SA 4.0 — 62, CC BY 2.0 — 33, CC BY-SA 2.0 — 24, CC0 — 22, CC BY-SA 3.0 — 21, общественное достояние — 11, CC BY 4.0 — 9, CC BY 3.0 — 7, CC BY 2.5 — 1.
- Ссылки на лицензии хранятся только в виде https; если у файла нет ссылки на лицензию (общественное достояние), показывается название лицензии и ссылка на страницу файла. Из поля автора убираются длинные пояснения загрузившего, остаётся имя.
- Чтобы пересмотреть фото рецепта, удалите его из `selection.json` и запустите workflow: для него снова появятся кандидаты.

## Требования лицензий

- **CC BY / CC BY-SA:** указаны автор, лицензия (со ссылкой) и источник. Копия уменьшена и перекодирована; это изменение формата, а не содержания.
- **CC BY-SA:** уменьшенная копия распространяется на тех же условиях. Ссылка на исходный файл ведёт на страницу Commons с полной информацией.
