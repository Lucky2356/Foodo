# Витамины: цели, единицы, источники

## Набор нутриентов

A, C, D, E, B6, B12, фолат. Единицы и формы хранятся явно:

| Нутриент | Данные продуктов Foodo | Примечание |
| --- | --- | --- |
| Витамин A | мкг RAE | в МР — мкг РЭ (ретиноловые эквиваленты): 1 мкг РЭ = 1 мкг ретинола = 6 мкг β-каротина = 12 мкг других каротиноидов, а в RAE — 12 и 24 мкг; формы несовместимы, цель не сравнивается |
| Витамин C | мг | |
| Витамин D | мкг | старше 65 лет — 20 мкг |
| Витамин E | мг альфа-токоферола | в МР — мг ТЭ; по приложению 2 МР 1 мг ТЭ = 1 мг α-токоферола — форма совпадает |
| B6 | мг | |
| B12 | мкг | |
| Фолат | мкг пищевых фолатов | в МР — мкг DFE; по приложению 2 МР 1 мкг DFE = 1 мкг пищевых фолатов — для обычной еды форма совпадает; синтетическая фолиевая кислота обогащённых продуктов не учитывается (потребление может быть занижено, не завышено) |

## Данные продуктов

338 из 445 продуктов берут значения из USDA FoodData Central, SR Legacy (апрель 2018, общественное достояние): номера нутриентов SR 208 (энергия), 203, 204, 205 (углеводы по разности), 291 (клетчатка), 320 (A, RAE), 401 (C), 328 (D2 + D3), 323 (α-токоферол), 415 (B6), 418 (B12), 432 (пищевые фолаты) — формы совпадают с формами Foodo, пересчёта нет. Нутриент, которого нет у записи, остаётся неизвестным (у USDA-продуктов чаще всего E — 45 продуктов и D — 37). Для будущего расчёта витамина A в РЭ по коэффициентам МР в `usda_values.json` сохранены ретинол и каротиноиды (319, 321, 322, 334); сейчас A в РЭ не рассчитывается. Остальные 107 продуктов — оценки разработчика. Порядок сопоставления — `docs/CATALOG.md`.

Пересчёт между разными формами (РЭ ↔ RAE и т. п.) **не выполняется**: если форма цели не совпадает с формой данных, цель показывается как «несовместимая форма» и не участвует в оценке. Формы E и фолатов совпадают с формами МР по определению самого документа (приложение 2), это не пересчёт.

## Наборы целей (`shared/data/nutrient_targets.json`)

| Набор | Статус | Для кого |
| --- | --- | --- |
| `mr-2.3.1.0253-21-adults` — МР 2.3.1.0253-21 «Нормы физиологических потребностей в энергии и пищевых веществах для различных групп населения РФ», Роспотребнадзор, 2021 | **сверено с текстом документа** (`verified`, версия `2026-10-28`) | взрослые 18+; A зависит от пола, D — от возраста |
| `demo-2026-10` | демонстрационный, **не норма** | только явный демо-сценарий и тесты; к реальным профилям не применяется |

Значения для взрослых сверены 28.10.2026 с текстом МР 2.3.1.0253-21: таблицы 11 (мужчины) и 16 (женщины), примечание о витамине D, приложение 2 «Коэффициенты пересчёта для эквивалентов витаминов». Источник текста — копия документа в КонсультантПлюс на сайте nios.ru (сайт Роспотребнадзора недоступен из среды разработки и иногда из сети GitHub; скрипт пробует оба адреса). Сверка повторяется автоматически: `scripts/reference/mr_norms.py --check` в workflow «Reference data» при каждом изменении `nutrient_targets.json` — расхождение с документом роняет проверку. Нормы для детей, беременных и кормящих (таблицы 20–21) в Foodo не используются.

Детям и подросткам цели из набора взрослых не назначаются. Верхние допустимые уровни не заданы — Foodo не делает выводов о превышении.

Пользователь может ввести цели участника вручную; ручные цели имеют приоритет и помечаются как введённые пользователем.

## Как витамины влияют на генератор

Переключатель «Учитывать витамины» (настройка семьи) включает слагаемое в рейтинг рецепта:

- для каждого участника и витамина считается цель на период (суточная цель × дни);
- прирост покрытия от порции блюда измеряется в «справедливых долях на приём пищи» и **ограничен одной долей** на пару участник/витамин — покрытие сверх цели ничего не добавляет, поэтому генератор не тянется к чрезмерным порциям;
- учитываются только полные значения (если у ингредиента витамин неизвестен — вклад не засчитывается и показывается неполнота);
- вес слагаемого 1 (сопоставим с предпочтениями), усреднение по участникам;
- исключения, порции, техника и бюджет остаются приоритетнее.

Влияние проверяется тестом на контролируемом наборе полных данных (4 рецепта, 12 seed): с включённым режимом покрытие выше. Фикстура `targets-balanced-vitamins` проверяет паритет TS/Python.

## Отчёт

Отчёт меню показывает для каждого участника за период: количество витамина, цель на период, процент покрытия и статусы:

- статус цели: `ok`, `no_target` (норма не выбрана или нет значения), `incompatible_form`, `demo_not_allowed` (демо-набор для реального профиля), `not_applicable` (например, возраст вне набора), `incomplete_data` (у части ингредиентов витамин неизвестен);
- статус набора: `verified`, `unverified`, `demo`, `manual`.
