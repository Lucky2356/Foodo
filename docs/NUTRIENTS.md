# Витамины: цели, единицы, источники

## Набор нутриентов

A, C, D, E, B6, B12, фолат. Единицы и формы хранятся явно:

| Нутриент | Данные продуктов Foodo | Примечание |
| --- | --- | --- |
| Витамин A | мкг РЭ (ретиноловые эквиваленты) | как в МР: 1 мкг РЭ = 1 мкг ретинола = 6 мкг β-каротина = 12 мкг других каротиноидов провитамина A (приложение 2); форма совпадает |

## Данные продуктов

338 из 445 продуктов берут значения из USDA FoodData Central, SR Legacy (апрель 2018, общественное достояние): номера нутриентов SR 208 (энергия), 203, 204, 205 (углеводы по разности), 291 (клетчатка), 320 (A, RAE — исходное значение), 319, 321, 322, 334 (ретинол, β- и α-каротин, β-криптоксантин), 401 (C), 328 (D2 + D3), 323 (α-токоферол), 415 (B6), 418 (B12), 432 (пищевые фолаты) — формы совпадают с формами Foodo. Нутриент, которого нет у записи, остаётся неизвестным (у USDA-продуктов чаще всего E — 45 продуктов и D — 37). Витамин A в РЭ считается при сборке каталога (`scripts/nutrition/vitamin_a.py`) по приложению 2 МР:

- есть ретинол и все три каротиноида — РЭ = ретинол + β-каротин / 6 + (α-каротин + β-криптоксантин) / 12 (280 продуктов);
- есть опубликованный RAE и ретинол — РЭ = 2 · RAE − ретинол: это следует из определений RAE и РЭ в том же приложении, без допущений о продукте;
- есть RAE и каротиноиды — РЭ = RAE + β-каротин / 12 + (α-каротин + β-криптоксантин) / 24;
- иначе витамин A неизвестен (16 продуктов USDA).

28 продуктов берут значения из Livsmedelsdatabasen Шведского агентства по продовольствию (Livsmedelsverket, CC BY 4.0, официальный API). Определения — по [коэффициентам пересчёта базы](https://www.livsmedelsverket.se/livsmedel-och-innehall/naringsamne/livsmedelsdatabasen/omlivsmedelsdatabasen/hur-tas-naringsvarden-fram/); переносится только то, что совпадает с формами Foodo (`scripts/nutrition/livsmedel.py`, `catalog_nutrients`):

- энергия (ккал), белки, жиры, клетчатка, витамины C, E (только α-токоферол, как у Foodo), B6, B12, фолаты — как опубликованы;
- углеводы в базе — «доступные»; углеводы Foodo по разности считаются по определению: 100 − вода − белок − жир − зола − алкоголь;
- витамин D в базе — D2 + D3 + 25-OH-D3 × 2,5, у Foodo — D2 + D3: не переносится;
- витамин A в базе — RAE только из ретинола и β-каротина, других каротиноидов в API нет; РЭ МР переносится лишь там, где база указывает β-каротин как логический ноль (продукт без каротиноидов) — тогда РЭ равен ретинолу (1 продукт из 28);
- шведские кисломолочные продукты обогащены витаминами A и D — у них A и D не переносятся.

Сайт финской базы Fineli (CC BY 4.0) закрыт для автоматических запросов проверкой Cloudflare; её не используем, обходить защиту не стали.

Остальные 79 продуктов — оценки разработчика. Оценки витамина A в них записаны в RAE, а доля ретинола в оценке неизвестна, поэтому в РЭ переводится только ноль; остальные оценки витамина A показываются как неизвестные (56 из 79 продуктов). Порядок сопоставления — `docs/CATALOG.md`.

Цели в другой форме (например, ручная цель витамина A в RAE) **не пересчитываются**: если форма цели не совпадает с формой данных, цель показывается как «несовместимая форма» и не участвует в оценке. Формы A, E и фолатов в данных совпадают с формами МР по определениям самого документа (приложение 2). РЭ для продуктов вычисляется из измеренных ретинола и каротиноидов, а не из общей пропорции.

Значения для взрослых сверены 28.10.2026 с текстом МР 2.3.1.0253-21: таблицы 11 (мужчины) и 16 (женщины), примечание о витамине D, приложение 2 «Коэффициенты пересчёта для эквивалентов витаминов». Источник текста — копия документа в КонсультантПлюс на сайте nios.ru (сайт Роспотребнадзора недоступен из среды разработки и иногда из сети GitHub; скрипт пробует оба адреса). Сверка повторяется автоматически: `scripts/reference/mr_norms.py --check` в workflow «Reference data» при каждом изменении `nutrient_targets.json` — расхождение с документом роняет проверку. Нормы для детей, беременных и кормящих (таблицы 20–21) в Foodo не используются.

Детям и подросткам цели из набора взрослых не назначаются. Верхние допустимые уровни не заданы — Foodo не делает выводов о превышении.

Пользователь может ввести цели участника вручную; ручные цели имеют приоритет и помечаются как введённые пользователем.

## Как витамины влияют на генератор

Переключатель «Учитывать витамины» (настройка семьи) включает слагаемое в рейтинг рецепта:

- для каждого участника и витамина считается цель на период (суточная цель × дни);
- прирост покрытия от порции блюда измеряется в «справедливых долях на приём пищи» и **ограничен одной долей** на пару участник/витамин — покрытие сверх цели ничего не добавляет, поэтому генератор не тянется к чрезмерным порциям;
- учитываются только полные значения (если у ингредиента витамин неизвестен — вклад не засчитывается и показывается неполнота);
- вес слагаемого 1 (сопоставим с предпочтениями), усреднение по участникам;
- исключения, порции, техника и бюджет остаются приоритетнее.

Влияние проверяется тестом на контролируемом наборе полных данных (4 рецепта, 12 seed): с включённым режимом покрытие выше. Фикстура `targets-balanced-vitamins` проверяет паритет TS/Python.

## Отчёт

Отчёт меню показывает для каждого участника за период: количество витамина, цель на период, процент покрытия и статусы:

- статус цели: `ok`, `no_target` (норма не выбрана или нет значения), `incompatible_form`, `demo_not_allowed` (демо-набор для реального профиля), `not_applicable` (например, возраст вне набора), `incomplete_data` (у части ингредиентов витамин неизвестен);
- статус набора: `verified`, `unverified`, `demo`, `manual`.
