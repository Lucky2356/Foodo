# Android-приложение (APK)

Приложение для Android собирается в GitHub Actions и выкладывается в релиз готовым файлом `.apk`. Внутри — та же гостевая версия Foodo, что и на сайте: она работает без сети и без сервера, данные хранятся на телефоне.

## Ключ подписи

Android устанавливает обновление поверх приложения, только если оно подписано тем же ключом. Поэтому ключ создаётся один раз и хранится только в секретах репозитория GitHub.

Одноразовая настройка:

1. Fine-grained token: только репозиторий `Lucky2356/Foodo`, разрешение **Secrets: Read and write**, срок 7 дней.
2. Секрет репозитория `SIGNING_SETUP_TOKEN` с этим токеном.
3. *Actions → Android signing key → Run workflow* на `main`. Workflow создаёт ключ RSA 4096 (PKCS12, 30 лет) и сохраняет секреты `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`. Пароль генерируется случайно и не попадает в журнал. Публичный отпечаток сертификата выводится в сводке запуска.
4. После успешного запуска удалить секрет `SIGNING_SETUP_TOKEN` и сам токен в настройках GitHub.

Повторный запуск откажется заменять существующий ключ. Секреты GitHub нельзя прочитать обратно: при потере ключа новые версии не установятся поверх старой, приложение придётся удалить и поставить заново.
