# Цены в Foodo

## Приоритет

Для каждого продукта выбирается одна цена:

1. **Своя цена семьи**: ручной ввод, чек или импорт. Всегда важнее любой публичной, даже если она старше.
2. **Цена выбранной сети в городе**:
   - собранная с сайта сети (`scraped`);
   - или медиана анонимных цен пользователей Foodo (`community`).

   Из двух берётся более свежая.
3. **Средняя цена Росстата** (`rosstat`): сначала по городу, если Росстат публикует его отдельно, затем по региону. Это оценка, а не цена магазина. В интерфейсе она помечена «оценка», и статус бюджета с такими ценами показывается как «по оценке».

Если цены нет ни в одном источнике, продукт остаётся без цены, а бюджет получает статус «не подтверждён». Цены не выдумываются.

Свежесть публичных данных: сайт сети — 45 дней, цены пользователей — 90 дней, Росстат — 120 дней.

## Источники и как они собираются

Сбор цен выполняет workflow **Prices** (`.github/workflows/prices.yml`), код находится в `scripts/prices/`:

- **Расписание:** еженедельно (понедельник, 03:17 UTC) и вручную (*Actions → Prices → Run workflow* на `main`).
- **Сохранение:** собранные данные коммитятся в `shared/data/prices/*.json` в `main`, после чего пересобирается сайт GitHub Pages.
- **Сервер:** получает данные при следующем `load_seed` (выполняется при каждом старте контейнера API; повторный импорт не создаёт дублей).
- **В PR:** workflow делает только пробный сбор (`--dry-run`), ничего не записывая.

Все запросы идут с честным User-Agent `FoodoPriceBot` и соблюдают `robots.txt` (группа `*`, самое длинное правило побеждает). Между запросами к сайту выдерживается пауза 1–3 секунды. Кэш и куки не используются, защиту от ботов сборщик не обходит.

### Росстат — средние потребительские цены

- **Откуда:** страница <https://rosstat.gov.ru/statistics/price>, файл `sred_potreb_cen_<MM>-<YYYY>.xlsx` (текущий год) или `sred_potreb_cen_<YYYY>.xlsx`. Берётся последний месяц: цены на конец месяца, руб. за единицу.
- **Территории:** регионы и около 280 городов, которые Росстат публикует отдельно. Города сопоставляются с `shared/data/geo/cities.json` по названию внутри региона. Для Архангельской и Тюменской областей используются строки «кроме автономных округов».
- **Товары:** соответствие кодов Росстата продуктам Foodo описано в `scripts/prices/rosstat.py` (`GOODS`). Продукты без честного аналога остаются без оценки: куриная грудка, пармезан, специи и т. п.
- **Пустые значения:** «…» и «-» в таблице означают отсутствие данных, а не ноль.
- **Сертификаты:** сайты Росстата используют корневой сертификат Минцифры (Russian Trusted Root CA), которого нет в публичных хранилищах. Сборщик загружает корневой сертификат с официального адреса Госуслуг, а промежуточный — по адресу из поля AIA сертификата сайта. Проверка TLS не отключается.

Статус каждого источника обновляется при каждом запуске и публикуется вместе с данными (`status.json`). В приложении его можно посмотреть в разделе *Настройки → Город и магазин → Источники цен*.

Сбор с недоступных сайтов возможен только с российского сервера и с разрешения сети, поэтому он оставлен на следующий этап. Обходить блокировки сборщик не будет.

### Цены пользователей

Пользователь с аккаунтом может включить переключатель «Делиться введёнными ценами анонимно».

- **Что передаётся:** продукт, цена, упаковка, сеть, город и дата. Автор хранится как хеш, который нельзя обратить без секрета сервера.
- **Как используется:** публичная цена — это медиана по сети и городу.
- **Ограничение:** только сервер. В гостевом режиме данные не покидают устройство.

## Форматы

- **Наблюдения** (`shared/data/prices/*.json`):
  - поля файла: `{"format": "foodo-price-observations", "kind": "rosstat"|"scraped", "observations": [...]}`;
  - поля наблюдения: `product_id`, `region`, `city_id` (необязательно для Росстата), `chain_id` (для сайтов), `price_kop`, `package_size`, `package_unit` (`g|kg|ml|l|pcs`), `loose`, `observed_on`, `source`, `source_url`, `external_id`.
- **Статический сайт** (`frontend/public/data/prices/`, создаётся `python -m scripts.prices.publish` при сборке):
  - `index.json` сопоставляет ключи `region:<регион>`, `city:<id>` и `<id города>:<сеть>` с небольшими файлами;
  - браузер скачивает только файлы своего города и передаёт только их имена.
- **Ручной импорт на сервере:** `python manage.py import_prices <file.json> --kind scraped|rosstat`.
